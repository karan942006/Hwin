# HackathonWin – AI-Powered Hackathon Operating System

Build a production-ready SaaS web application called **HackathonWin** using **React, TypeScript, Tailwind CSS, Shadcn UI, Supabase Authentication, Supabase Database, Supabase Realtime, Supabase Storage, and Edge Functions**.

The application should look modern, futuristic, premium, and designed specifically for hackathons. Use glassmorphism, smooth animations, gradients, dark/light mode, responsive design, and professional dashboards.

## Core Concept

HackathonWin is an AI-powered collaborative workspace where up to 5 team members can work simultaneously to build and manage a hackathon project from idea to final submission.

The platform should combine:

* Team collaboration
* Project management
* AI idea generation
* AI code generation
* AI app generation
* AI pitch generation
* AI documentation generation
* AI judge simulator
* Real-time communication
* File sharing
* Progress tracking
